# 🚀 Learnova — Advanced Student Analytics Platform

Learnova is a multi-layered dashboard suite engineered to help students track test performance, analyze progress, and receive personalized study coaching.

## 🏗️ Technical Architecture Matrix
The platform unifies desktop execution speed with advanced cloud integrations:
- **Frontend Core:** HTML5, CSS3 Custom Theme Variables, JavaScript ES6.
- **Embedded Shell Container:** PySide6 (Qt for Python) with persistent Chromium profile caching rules.
- **Microservice Backend:** Node.js Express server instance executing on detached background threads.
- **Isolated Storage Ledger:** Cross-platform asynchronous Lowdb layout sandboxed inside system AppData.
- **Local AI Brain Engine:** StudyBot AI assistant powered by Ollama running a Qwen2.5 model instance.

## 🎨 Feature Ecosystem
- 📈 **Performance Analytics:** Dynamic JavaScript data matrices displaying subject-wise velocity charts.
- 🤖 **StudyBot AI Assistant:** Network-optimized conversational coach providing customized revision sheets.
- 📍 **Geocoding & Leaflet Maps:** Interactive mapping engine to securely log school location coordinates.
- 💾 **Enterprise Data Separation:** Core student records are kept completely secure from application installer updates.

## 🛠️ Unified Compiler Pipeline
To bundle the entire architecture into a clean, standalone Windows distribution package:
```bash
python build.py
```
*The script automatically sweeps lingering port locks, handles cache folders, calls PyInstaller, and outputs `Learnova_Setup.exe` into the workspace root.*
